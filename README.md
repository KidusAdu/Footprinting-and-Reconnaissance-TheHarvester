# 🔐 Footprinting & Reconnaissance Attacks Using TheHarvester

## 📌 Project Overview

This project demonstrates practical implementation of **Footprinting and Reconnaissance** in Cybersecurity using TheHarvester on Kali Linux.

The project focuses on passive information gathering, Open-Source Intelligence (OSINT), domain reconnaissance, identifying publicly available information, analyzing collected results, and preparing professional security assessment documentation.

It includes practical documentation, reconnaissance evidence, findings analysis, and a penetration testing report.

## 🎯 Project Objectives

- Understand the concept of Footprinting and Reconnaissance.
- Implement TheHarvester in Kali Linux.
- Perform passive OSINT information gathering.
- Identify publicly available domains, subdomains, IP addresses, and ASNs.
- Analyze reconnaissance results and provider limitations.
- Document security observations and potential risks.
- Prepare a structured cybersecurity assessment report.

## ⚠️ Ethical Considerations

This project is intended for educational purposes and authorized security assessments.

The documented exercise includes passive reconnaissance against the domain recorded in the supplied evidence. The report does not establish authorization from that domain owner, confirm vulnerabilities, or demonstrate exploitation.

Only perform security testing against systems you own or have explicit written permission to assess.

Sensitive information, credentials, tokens, and authentication-related URL parameters should be removed before publishing evidence.
